# 消火栓マップ

横浜市港北区 篠原北・篠原町・錦が丘・富士塚周辺の消火栓の位置を表示する地図です。

公開ページ: https://ducati696.github.io/hydrant/

- 現在地から近い順に、最寄り3箇所を赤・黄・青の大きいピンで表示します(その他は緑)。左下に番号と距離の一覧が出ます。
- 一度開いておけば、通信できない場所でも地図と消火栓を表示できます。
- 端末のダークモード設定に合わせて、夜間は暗い配色になります。
- 最寄りの登録消火栓まで 200 m を超えると、登録範囲外の警告を出します。
- 吹き出しの「補助情報」は、入力した端末のブラウザにだけ保存されます。

地図は[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)の標準地図タイルを使っています。

## 消火栓データの更新手順

データは `hydrants.geojson` に入っています。変更するときは次の2つを必ず行ってください。

1. `features` の中の消火栓を追加・修正する。
2. **ファイル先頭の `"updated"` を変更した日付(`YYYY-MM-DD`)に直す。**

`updated` を直さずにデータだけ変えると、データチェックがエラーになります。この日付は地図の右下に「消火栓 51件(2026-11-15 更新)」のように表示されます。

### 消火栓1件の書き方

1件を1行で書きます。

```json
{"type":"Feature","id":52,"geometry":{"type":"Point","coordinates":[139.6270982,35.509137]},"properties":{"number":52,"name":"消火栓 No.52（地下式）","type":"地下式","address":"〒222-0021 神奈川県横浜市港北区篠原北１丁目付近","aux_info":"","created":"2026-11-15T01:00:00Z"}},
```

| 項目 | 内容 |
| --- | --- |
| `id` と `number` | 同じ番号にします。追加するときは、いちばん大きい番号の次を使います。番号は重複させません。 |
| `coordinates` | **[経度, 緯度]** の順です(Google マップの表示とは逆)。数値で書き、引用符は付けません。 |
| `name` | `消火栓 No.52（地下式）` の形にします。番号と種類を `id`・`type` に合わせます。 |
| `type` | `地下式` か `地上式` のどちらかです。 |
| `address` | 住所です。分からなければ `""` にします。 |
| `aux_info` | 吹き出しの「補助情報」の初期値です。なければ `""` にします。 |
| `created` | 登録した日時です(省略できます)。 |

最後の1件の行末にはカンマを付けません。

## データチェック

`hydrants.geojson` を変更してコミットすると、GitHub Actions の「データチェック」が自動で動きます。結果はリポジトリの Actions タブで確認できます。手動で動かすときは、Actions タブの「データチェック」から「Run workflow」を押します。

エラーになるもの(✕ が付きます):

- JSON として読めない、`updated` がない、日付の形式が違う、未来の日付になっている
- データを変えたのに `updated` が前のまま、または前より古い日付に戻っている
- 番号の重複、`id` と `number` の不一致
- 緯度と経度が逆、座標が日本の範囲外、座標が数値でない、他の消火栓と座標がまったく同じ
- `name` が空、`type` が `地下式`・`地上式` 以外

警告だけのもの(実行は成功します):

- 他の消火栓から 3 km 以上離れている
- 他の消火栓と 5 m 未満しか離れていない(重複登録の疑い)
- 名前と番号・種類が合っていない

データチェックが失敗しても、公開ページの更新は止まりません。✕ が付いたらデータを直してコミットし直してください。

Node.js がある環境では、手元でも確認できます。

```bash
node scripts/check-data.mjs
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 地図のページ本体 |
| `hydrants.geojson` | 消火栓のデータ |
| `sw.js` | オフライン対応(ページ・データ・地図タイルの保存) |
| `scripts/check-data.mjs` | データチェックの本体 |
| `.github/workflows/check-data.yml` | データチェックを GitHub Actions で動かす設定 |

## 変更するときの注意

- `index.html` で読み込むライブラリの URL を変えたら、`sw.js` の `PRECACHE_URLS` も同じ URL に直してください。
- 地図タイルの保存先の名前 `TILE_CACHE` は、`index.html` と `sw.js` で同じにしてください。
- ページやデータを更新すると、利用者の端末には次に通信できる状態で開いたときに反映されます。
